# Bending Spoons

> Bending Spoons S.p.A. (Nasdaq: BSP) is a Milan, Italy technology company founded in 2013 that acquires established digital products and operates them for the long term. Its portfolio spans more than 50 acquisitions — AOL, Brightcove, Eventbrite, Evernote, Harvest, Issuu, komoot, Loomly, Meetup, Remini, Splice, StreamYard, Tractive, Vimeo and WeTransfer among them — serving over 500 million monthly active users.

Important for agents: **Bending Spoons publishes no public developer API, API reference, or developer portal at the holding-company level.** Every API in the group belongs to one of the acquired products, each of which documents and versions its API independently. Do not attempt to call an `api.bendingspoons.com` host — no such host resolves. This file was generated by API Evangelist from the company's public surface; it is not published by Bending Spoons.
